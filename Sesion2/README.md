## Problemática
Una bodega de barrio no tiene forma organizada de saber qué productos 
tiene disponibles ni su stock, lo que genera pérdida de ventas.

## Funcionalidades
- Listado de productos ordenado por categoría
- Registro de nuevo producto mediante formulario
- Validación de precio y stock, no permite números negativos
- Validación de nombre duplicado
