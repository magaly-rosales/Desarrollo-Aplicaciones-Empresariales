# GLAB-S02 - Tienda de Barrio

## Ejercicio 1 - Problemática
Una bodega de barrio no tiene forma organizada de saber qué productos 
tiene disponibles ni su stock, lo que genera pérdida de ventas cuando 
no se sabe qué reponer. Lo usaría el dueño o encargado de la bodega.

## Ejercicio 2 - Requisitos funcionales
1. Registrar un nuevo producto (nombre, precio, stock, categoría)
2. Ver el listado de todos los productos disponibles
3. Visualizar el stock actual de cada producto
4. Identificar la categoría de cada producto
5. Validar que precio y stock sean valores numéricos válidos

## Ejercicio 3 - Modelo de datos (Producto)
| Campo     | Tipo    | Obligatorio | Justificación                   |
| --------- | ------- | ----------- | ------------------------------- |
| nombre    | str     | Sí          | Identifica el producto          |
| precio    | decimal | Sí          | Necesario para venta/validación |
| stock     | int     | Sí          | Controla disponibilidad         |
| categoria | str     | Sí          | Permite clasificar productos    |
## Ejercicio 4 - Nueva App
